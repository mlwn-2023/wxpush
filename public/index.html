INTEGRATIONS

API 接入

支持 SmsForwarder 兼容签名、分类推送与持久化防重放。

生产环境必须签名API Token 同时作为签名 secret；时间戳有效期一小时，相同签名只能使用一次。

接口地址

POST /wxsend

SmsForwarder 配置

WebServer: http(s)://你的WXPush地址/wxsend?token=YOUR_API_TOKEN&group=服务器告警
secret:    YOUR_API_TOKEN
请求方式:  POST（推荐）

SmsForwarder 的 from 自动作为标题，content 作为正文，无需修改模板。

签名规则

stringToSign = timestamp + "\n" + API_TOKEN
sign = urlEncode(base64(hmacSHA256(stringToSign, API_TOKEN)))

POST JSON 示例

curl -X POST http://NAS_IP:3939/wxsend \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"timestamp":"毫秒时间戳","sign":"签名","group":"服务器告警","title":"服务通知","content":"任务已完成"}'

收件人选择规则

  1. userid：指定一个或多个 OpenID，优先级最高。
  2. group / groups：发送给分类内所有已启用联系人。
  3. 均不传：发送给全部已启用联系人。

兼容 GET：/wxsend?token=...&timestamp=...&sign=...&group=...&title=...&content=...

重放请求返回 403 Replay request rejected。公网调用仍需使用 HTTPS。

新建调用 Token

建议为每个系统单独创建。Token 也是该系统的签名 secret，生成后只显示一次。

调用方 Token

可独立停用或删除，不影响其他系统；停用后鉴权和签名会同时失效。
